About InputTest.online

A free, browser-based hardware diagnostic platform — no downloads, no sign-ups, no data collection.

🎯 Our Mission & Hardware Philosophy

InputTest.online was founded with a dedicated technical mission: to provide gamers, hardware engineers, developers, and computer technicians with an industrial-grade diagnostic suite that operates 100% inside modern web browsers without installing native software drivers, bloatware, or invasive executables.

Whether you are verifying the switch rollover (NKRO) on a high-end mechanical keyboard, assessing sensor jitter and polling stability on an 8000Hz gaming mouse, or testing stick drift on a modern controller, InputTest offers laboratory-grade diagnostic metrics with zero latency and zero data collection.

🔬 Diagnostic Engineering & W3C Standards Compliance

Every diagnostic module across our 23+ tools interfaces directly with low-level browser APIs standardized by the World Wide Web Consortium (W3C). We bypass artificial operating system smoothing to capture raw hardware interrupts:

Pointer Events Level 3

Powers our Mouse Polling Rate and Sensor Jitter checkers via pointerrawupdate and microsecond performance.now() timestamps, accurately tracking interval deltas up to 8,000Hz.

Web Audio API

Enables real-time acoustic transient profiling, 2048-point Fast Fourier Transform (FFT) spectrograms, and micro-chatter switch detection with zero server recording or external uploads.

Standard Gamepad API

Continuous 60–120FPS polling loops analyze analog axis deflection down to 0.0001 precision, detecting deadzone thresholds, stick drift, and trigger pressure curves.

WebHID & WebUSB Standards

Safely interrogates USB peripheral Vendor IDs (VID), Product IDs (PID), and Human Interface Device descriptor trees under explicit user permission grants.

📐 Measurement Precision & Calibration Protocol

Traditional online tests rely on standard millisecond system clocks (Date.now()), which introduce jitter and 15–20ms quantisation noise. In contrast, InputTest.online executes all temporal calculations using the browser's High Resolution Time API:

✓ Temporal Resolution: Sub-millisecond (5 to 20 microsecond precision)
✓ Jitter Calculation: Rolling circular buffer variance with standard deviation analysis
✓ Latency Profiling: True round-trip requestAnimationFrame & AudioContext loopback

🔒 Sandboxed Zero-Telemetry Guarantee

User privacy is our foremost architectural requirement. Unlike benchmark software that requires administrative operating system access or uploads telemetry packets:

  • ✓ Zero External Transmission: Keystroke logs, audio buffers, and hardware telemetry remain strictly inside volatile browser heap memory.
  • ✓ No Account Barrier: We do not require usernames, passwords, or emails to perform comprehensive hardware evaluations.
  • ✓ Immediate Garbage Collection: Closing the tab or resetting a test instantly purges all recorded benchmarks from system RAM.
